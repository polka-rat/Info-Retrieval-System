\subsection{Cosine Similarity and Ranking}
\begin{enumerate}
    \item $|Q|=0.4771$
    \item $|d1|=5*\sqrt{(0.4771)^2}=5*0.4771=2.3855$
    \item $|d2|=6*\sqrt{(0.4771)^2}=2.8626$
    \item $|d3|=6*\sqrt{(0.4771)^2}=2.8626$
    \item $cos\theta_{d1}=\frac{Q.d1}{|Q||d1|}=\frac{04771*0.4771}{0.4771*5*0.4771}=0.2$
    \item $cos\theta_{d2}=\frac{Q.d2}{|Q||d2|}=0$
    \item $cos\theta_{d3}=\frac{Q.d3}{|Q||d3|}=0$
\end{enumerate}

\begin{itemize}
    \item Final Ranking is $d1>d2=d3$
    \item Yes, Ranking is desirable as d1 would have been the most likely document we would have been searching for, given the query.
\end{itemize}

\subsection{Analysis of Word Sense Ambiguity}
\begin{enumerate}
    \item In the query ``movie star'', ``star'' appears in all the documents so the query reduces to movie alone. The word ``movie'' appears only in document d2, so ideally, only d2 should be retrieved.
    \item Using either Inverted Index (movie has only doc d2 in its inverted index) or TF-IDF weights (d1 and d3 will have 0 cosine similarity with the query) will correctly retrieve d2.
    \item In this corpus, star appears in all the documents, so the system cannot distinguish the meaning of star (it has IDF $=0$).
    \item The system ignores it entirely in the retrieval of documents.
    \item If the query was just ``star'', all the docs will score equally and the system would fail.
    \item Hence, word sense ambiguity causes important query terms to lose discriminative power when they appear across multiple contexts.
\end{enumerate}
