This report consolidates the full assignment workflow for our Information Retrieval system using the Cranfield dataset. It includes a manual retrieval example, evaluation of a baseline TF-IDF system, an analysis of Vector Space Model limitations, and an extended project exploring multiple retrieval enhancements including LSA, n-gram matching, Word2Vec retrieval, statistical language modeling, BM25+, neural reranking, and Learning-to-Rank. The report follows the `Main.tex` template structure while preserving the substantive content from our original `custom.tex`.
